# 卡窗 · 赶早八：UI 与交互 Demo

本目录是 C 的独立前端原型，覆盖睡眠选择、榴园宿舍接路、校园小公交卡点上车、食堂钻空隙买包子、第一教学楼扫码签到，以及成功 / 失败结算。

当前使用浏览器本地演示规则，尚未接入团队 Python 服务。建筑与位置为示意，签到码仅为游戏图案。

## 本地运行

在仓库根目录执行（需要 Python 3）：

```bash
python -m http.server 5173 --directory ui-demo
```

然后打开 http://localhost:5173 。HTML、CSS、JavaScript 和 SVG 均为本地资源，无需安装前端依赖。

## 操作

- 按住 Space：卡住世界；松开：继续运行。
- 也可点击“锁定卡顿”，拖动后点击恢复。
- 卡顿期间拖动窗口标题栏、食堂通道或手机框。
- R：重试当前关；Escape：暂停 / 继续。
- 可拖对象聚焦后支持方向键微调，Shift + 方向键加大步长。
- 每关独立补充卡顿预算，失败可回到关卡入口重试。
- 地图页“先试一段”可直接体验某一关，再继续剩余流程。

## 文件与整合边界

| 文件 | 内容 |
| --- | --- |
| index.html | 页面骨架、校园示意地图、宿舍关卡基础布局 |
| tokens.css | 配色、字体与基础设计变量 |
| journey.css | 睡眠、小公交、食堂与暂停界面的补充样式 |
| pixel.css / pixel-art.mjs / assets/*.svg | 像素界面、校园地图与角色家具素材 |
| journey.js | UI、交互、场景流转与音效接入 |
| mechanics.mjs | 本地演示规则与状态，供 A、B 对照替换 |
| tests/mechanics.test.mjs | 规则回归与完整路线验证 |

B 负责正式机制与接口；mechanics.mjs 是本次 Demo 的可替换演示实现，不要求后端按此文件结构实现。A 负责把正式机制接入运行与交互；C 继续维护视觉和反馈。

## 验证

需要 Node.js：

```bash
node --test ui-demo/tests/mechanics.test.mjs
```

8 项测试覆盖睡眠起床时间、冻结与预算、暂停、道路断开、公交时机、人群碰撞、截止、关卡重试，以及三种睡眠选择下的完整通关路线。

浏览器分段试玩通过：宿舍卡合与跨窗、小公交对接、食堂三组人群、买包子后扫码签到、失败重试与暂停继续。
